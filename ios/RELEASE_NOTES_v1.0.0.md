## 安装

本 IPA 仅做了 ldid 临时签名，不能直接安装，需要先用自己的证书重签：

1. 用轻松签 / ESign / Sideloadly / TrollStore 等工具导入 IPA；
2. 选择自己的签名证书（或 TrollStore 直接安装）；
3. 安装后首次启动请允许通知权限，否则截止提醒不会触发。

覆盖安装不会清除已有数据（数据保存在应用沙盒的 NSUserDefaults 中，升级前仍建议先在「我的 → 导出数据」备份一份）。
